When the vector table must live in RAM but the hardware starts with ROM at 0x0, boot code copies the table and flips a remap bit.

On Cortex-M nothing sets the PC for you. The core reads the first two words of the vector table, then starts executing.

The immutable BootROM (first immutable code) loads and checks the first mutable code (FMC), which loads the rest.
