1. Function call and LR

Core rule

Function call and LR

  • BL writes LR, BX LR reads it
  • A function that calls another function must save LR first

Example program

0x0800_0100 main: BL foo
0x0800_0104       ADD R2, R0, #1
0x0800_0200 foo:  PUSH {LR}
0x0800_0202       BL bar
0x0800_0206       POP {PC}
0x0800_0300 bar:  ADDS R0, R0, #1
0x0800_0302       BX LR

Trace

Classic bug

Skipping the PUSH

  • BL bar overwrites LR with 0x207, main's address is lost
  • foo returns to itself and loops forever

Detail

Why LR shows 0x105, not 0x104

  • Bit 0 is the Thumb flag, set by BL on purpose
  • Cortex-M has no ARM mode; bit 0 = 0 causes INVSTATE fault
  • CPU ignores bit 0 for the actual jump, so PC = 0x104
  • Function pointers are odd too (0x...201)

2. Task switch (PendSV)

Triggers

SysTick and PendSV

  • SysTick fires every 1 ms and sets the PendSV pending bit
  • PendSV has the lowest priority, so it runs after all other ISRs
  • A task can also trigger it (yield, block on semaphore)

Flow

Task A to Task B

1PendSV fires, A interrupted. Handler uses MSP, tasks use PSP
HWPushes xPSR, PC, LR, R12, R3-R0 on PSP. Saved PC is where A resumes, saved LR is A's own LR
SWMRS R0, PSP then STMDB R0!, {R4-R11}
TCBtcbA->sp = R0, state READY or BLOCKED
SCHScheduler picks B, currentTCB = tcbB
TCBR0 = tcbB->sp, state RUNNING
SWLDMIA R0!, {R4-R11} then MSR PSP, R0 (mirror of the push)
HWLR = 0xFFFFFFFD, BX LR: hardware pops R0-R3, R12, LR, PC, xPSR
9B resumes at its saved PC with registers and flags intact

Key facts

Easy to mix up

  • Stack layout low to high: R4-R11 (software), then R0-R3, R12, LR, PC, xPSR (hardware)
  • Inside the handler LR is reused as EXC_RETURN 0xFFFFFFFD (thread mode, PSP). A's real LR is safe on its stack
  • xPSR holds flags N Z C V, exception number and T bit; hardware saves and restores it

New task

Fake initial frame

  • xPSR = 0x01000000 (T bit set, else fault)
  • PC = task function, LR = task_exit, R0 = argument
  • R12, R1-R3, R4-R11 = 0
  • tcb->sp = address of the R4 slot (lowest word)

Code

PendSV handler skeleton

PendSV_Handler:
  MRS   R0, PSP
  STMDB R0!, {R4-R11}
  BL    save_sp_and_pick_next
  LDMIA R0!, {R4-R11}
  MSR   PSP, R0
  LDR   LR, =0xFFFFFFFD
  BX    LR
