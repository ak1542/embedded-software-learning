bit tricks on A = 01101000
Two expressions worth knowing cold
isolate lowest set bit
A & -A
01101000
& -A (two’s complement)
00001000
Only the rightmost 1 survives.
clear lowest set bit
(A - 1) & A
01101000
& (A-1)
01100000
This is NOT "find first set bit".
count set bits (Kernighan)
int n = 0;
while (A) { A = (A - 1) & A; n++; }
iteration 0
01101000
iteration 1
01100000
iteration 2
01000000
iteration 3
00000000
3 iterations = 3 set bits. The loop runs once per set bit, not once per bit position.
power of two
int is_pow2(uint32_t A) { return A && !((A - 1) & A); }
A power of two has exactly one set bit, so clearing it gives 0. The A && part rejects A = 0.
