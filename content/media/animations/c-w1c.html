hardware register
W1C: write-1-to-clear
Writing a 1 to a bit clears it. Writing a 0 does nothing. Example: STATUS = 0b111, we want to clear bit 0 only.
normal read-modify-write
❌ Clears the wrong bits
status  = *reg;      // 0b111
status &= ~0x1;     // 0b110
*reg    = status;   // write 0b110
↓
Bits 1 and 2 are written as 1 → the hardware clears them.
STATUS = 0b001 ✖ (wanted 0b110)
correct
✅ Write only the bit to clear
*reg = (1U << 0);   // write 0b001
↓
Only bit 0 is written as 1; the zeros leave the other bits alone.
STATUS = 0b110 ✔
rule
Check the access type of every bit in the datasheet
RW (normal), W1C, W1S, RO, RC (clear on read)… A normal reg &= ~mask is only safe for plain RW bits. A RAM variable is fine; a hardware register can have side effects on read and on write.
